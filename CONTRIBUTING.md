# Contributing Guide | Guia de Contribuição

**PT-BR**  
Obrigado pelo interesse em contribuir com este projeto.

Este repositório segue algumas diretrizes simples para manter o código limpo,
consistente e fácil de manter.

**EN**  
Thank you for your interest in contributing to this project.

This repository follows a few simple guidelines to keep the codebase clean,
consistent and maintainable.

---

## How to Contribute | Como Contribuir

**PT-BR**
Você pode contribuir das seguintes formas:
- Reportando bugs
- Sugerindo melhorias
- Abrindo pull requests
- Melhorando a documentação

**EN**
You can contribute by:
- Reporting bugs
- Suggesting improvements
- Opening pull requests
- Improving documentation

---

## Issues

**PT-BR**
Antes de abrir uma issue:
- Verifique se ela já não existe
- Seja claro e objetivo na descrição
- Inclua passos para reprodução, se aplicável

**EN**
Before opening an issue:
- Check if the issue already exists
- Provide clear and objective descriptions
- Include steps to reproduce, if applicable

---

## Pull Requests

**PT-BR**
Ao abrir um Pull Request:
1. Faça um fork do repositório
2. Crie uma branch a partir da `main`
3. Mantenha as alterações focadas
4. Siga os padrões existentes do código
5. Use mensagens de commit claras
6. Garanta que o projeto esteja compilando corretamente

Pull Requests pequenos e objetivos são preferíveis.

**EN**
When opening a Pull Request:
1. Fork the repository
2. Create a feature branch from `main`
3. Keep changes focused and well-scoped
4. Follow existing code patterns
5. Write clear commit messages
6. Ensure the project builds correctly

Small, focused pull requests are preferred.

---

## Code Style | Estilo de Código

**PT-BR**
- Siga a estrutura existente do projeto
- Priorize legibilidade e consistência
- Evite alterações não relacionadas no mesmo PR

**EN**
- Follow the existing project structure
- Keep code readable and consistent
- Avoid unrelated changes in the same PR
