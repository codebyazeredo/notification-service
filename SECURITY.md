# Security Policy | Política de Segurança

## Supported Versions | Versões Suportadas

**PT-BR**  
Este projeto está em desenvolvimento ativo.  
Apenas a **versão mais recente da branch `main`** recebe atualizações de segurança.

**EN**  
This project is under active development.  
Only the **latest version on the `main` branch** is supported with security updates.

---

## Reporting a Vulnerability | Reportando uma Vulnerabilidade

**PT-BR**  
Se você identificar uma vulnerabilidade de segurança, **não abra uma issue pública**.

Reporte de forma responsável entrando em contato diretamente com o mantenedor.

**EN**  
If you discover a security vulnerability, **do not open a public issue**.

Please report it responsibly by contacting the maintainer directly.

---

### How to report | Como reportar

**PT-BR**
- Descreva claramente a vulnerabilidade
- Inclua passos para reprodução, se possível
- Informe a versão ou commit afetado

**EN**
- Provide a clear description of the vulnerability
- Include steps to reproduce, if possible
- Mention the affected version or commit

---

Relatos de segurança serão tratados com prioridade.

## Response Policy | Política de Resposta

**PT-BR**
- Relatos serão analisados o mais rápido possível
- Vulnerabilidades válidas serão corrigidas prontamente
- Créditos ao relator podem ser concedidos, se desejado

**EN**
- Reports will be reviewed as soon as possible
- Valid vulnerabilities will be addressed promptly
- Credit may be given to reporters, if desired

Thank you for helping keep this project secure.  
Obrigado por ajudar a manter este projeto seguro.
